# Statistical methods for medical research

Red Door Analytics is a Stockholm biostatistics consultancy: applied statistics for medical research, open-source survival-analysis software, and training. We build the methods and the software ourselves.

[reddooranalytics.se →](https://reddooranalytics.se/) · [The software →](https://reddooranalytics.se/software/) · [Courses →](https://reddooranalytics.se/services/training-courses/) · [Get in touch →](https://reddooranalytics.se/contact/)

## Packages

- [**morgana**](https://github.com/RedDoorAnalytics/morgana) · Bayesian flexible parametric survival models in Stata · [its page →](https://reddooranalytics.se/software/morgana/)
- [**stexcess**](https://github.com/RedDoorAnalytics/stexcess) · flexible parametric excess hazard models in Stata, with a modelled expected rate · [its page →](https://reddooranalytics.se/software/stexcess/)
- [**stmerlin**](https://github.com/RedDoorAnalytics/stmerlin) · parametric and semi-parametric survival models in Stata, optionally on multiple timescales · [with merlin for Stata →](https://reddooranalytics.se/software/merlin/stata/)

Each installs from reddooranalytics.se; the install line is in its README.

Questions about any of our packages: contact@reddooranalytics.se
